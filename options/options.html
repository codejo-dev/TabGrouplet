    Matching

    Each rule tests a regular expression against the tab's full URL, e.g. https://mail.google.com/mail/u/0. The URL includes the port when it has one (http://localhost:3000/). Matching ignores upper/lower case. Rules are checked from top to bottom and the first match wins. Pinned tabs are never grouped.

    Group names

    The group name is a template. These tokens are replaced with parts of the match:

    $1 … $9capture group 1–9
    $<name>named capture group (?<name>…)
    $&the whole match
    $$a literal dollar sign

    Tabs whose names come out the same share a group. A fixed name like 💻 puts every match in one group, while $1 makes one group per distinct capture. Emoji work anywhere in the name.

    Color, threshold and position

    Color is optional. On Auto, a new group gets the color least used by the other groups in its window. Chrome only offers these nine colors.

    Group when at least N tabs match counts per window, since Chrome groups can't span windows. Below N the group is dissolved again.

    Position is optional. 1 puts the group first (after pinned tabs), 2 second, and so on. Negative numbers count from the right, so -1 is last. Groups that share a position follow the order of their rules (higher in the list = further left); groups from the same rule are sorted by name.

    Your own groups

    Tab Grouplet only manages the groups it creates. Groups you make yourself, and the tabs in them, are left alone. If you drag a tab out of a managed group, it goes back on the next tab change in that window. Use the toolbar popup to pause.
